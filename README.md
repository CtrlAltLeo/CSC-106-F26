### Micro Keybinds
`ctrl + s` Save
`ctrl + q` quit
`ctrl + c` copy
`ctrl + v` paste

1. `cd` into the folder
2. `git branch lastname-firstname`
3. `git checkout lastname-firstname`

# Committing Changes

1. `git add .`
2. git commit -m <message>
